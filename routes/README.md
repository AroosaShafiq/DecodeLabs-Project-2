# DecodeLabs Project 2 - REST API

A beginner-friendly REST API built using Node.js and Express.js.

## Technologies Used

- Node.js
- Express.js
- JavaScript
- REST API
- Postman

## Features

- Get all tasks
- Get a task by ID
- Create a new task
- Update a task
- Delete a task
- Input validation
- 404 error handling

## API Endpoints

| Method | Endpoint       | Description    |
| ------ | -------------- | -------------- |
| GET    | /api/tasks     | Get all tasks  |
| GET    | /api/tasks/:id | Get task by ID |
| POST   | /api/tasks     | Create a task  |
| PUT    | /api/tasks/:id | Update a task  |
| DELETE | /api/tasks/:id | Delete a task  |

## How to Run

```bash
npm install
node server.js
```
